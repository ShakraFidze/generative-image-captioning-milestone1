# Generative Image Captioning Project — Milestone #1

**Students:** Tatenda Mwashaireni and Shakra Fidze

## Project Overview

This project develops a baseline image-captioning pipeline using PyTorch, Hugging Face Transformers, OpenAI CLIP, and GPT-2 tokenization.

The goal of Milestone #1 is to prepare an image-caption dataset, extract image embeddings, tokenize captions, and evaluate five sample image-caption pairs.

## Dataset

**Dataset:** Flickr8k

- 5,000 cleaned image-caption pairs
- 3,888 unique images
- Image preprocessing for CLIP
- Caption cleaning and tokenization

## Models and Technologies

- **Python:** Main programming language
- **PyTorch:** Deep learning framework
- **Hugging Face Transformers:** Pretrained model integration
- **CLIP (ViT-B/32):** Image feature extraction
- **GPT-2 Tokenizer:** Caption tokenization
- **Google Colab:** Notebook execution environment

## Methodology

1. Load the Flickr8k dataset.
2. Select and clean 5,000 image-caption pairs.
3. Preprocess images using the CLIP image processor.
4. Extract image embeddings with the pretrained CLIP model.
5. Tokenize captions using the GPT-2 tokenizer.
6. Evaluate five sample image-caption pairs.
7. Record similarity scores and visualize the results.

## Experimental Results

The baseline pipeline processed 5,000 image-caption pairs and 3,888 unique images.

Five sample image-caption matching tests were completed.

**Mean CLIP similarity score:** 0.3227

These results measure image-caption compatibility using CLIP. They do not represent captions newly generated by a trained caption decoder.
